# PeerOnQ dependency inventory

Status date: 2026-08-18. PeerOnQ remains MIT licensed, but every dependency keeps its own
license and redistribution terms. This file identifies the authoritative inventories and the
current release blockers; it is not a substitute for the exact-artifact SPDX SBOM.

## Authoritative manifests

- .NET versions: `Directory.Packages.props`; consumers: project `*.csproj` files.
- JavaScript versions: `pnpm-lock.yaml`, `pnpm-workspace.yaml` and workspace `package.json` files.
- Containers: Dockerfiles and Compose definitions under `deploy/`.
- Windows installer: `installer/PeerOnQ.Installer.wixproj` and its locked WiX extension.
- Exact release payload: SPDX 2.2 plus dependency, license, vulnerability and native-binary
  evidence generated by `scripts/windows/new-phase5-local-evidence.ps1`.
