# PeerOnQ dependency inventory

Status date: 2026-09-27. PeerOnQ remains MIT licensed, but every dependency keeps its own
license and redistribution terms. This file identifies the authoritative inventories and the
current release blockers; it is not a substitute for the exact-artifact SPDX SBOM.

## Authoritative manifests

- .NET versions: `Directory.Packages.props`; consumers: project `*.csproj` files.
- JavaScript versions: `pnpm-lock.yaml`, `pnpm-workspace.yaml` and workspace `package.json` files.
- Containers: Dockerfiles and Compose definitions under `src/PeerOnQ.Infrastructure.Deployment`,
  `src/PeerOnQ.Realtime.Deployment` and `deploy/`.
- Windows installer: `installer/PeerOnQ.Installer.wixproj` and its locked WiX extension.
- Exact release payload: SPDX 2.2 plus dependency, license, vulnerability and native-binary
  evidence generated by `scripts/windows/new-phase5-local-evidence.ps1`.

## 2026-09-27 Node 24 contract and JavaScript review

The supported runtime is Node 24: root `engines.node` is `24.x`, `.nvmrc` selects `24`,
and `pnpm-workspace.yaml` enforces `engineStrict: true`. CI and Replit already select Node 24.
The prior `@types/node` 25.9.5 lock did not demonstrate a Node 25 runtime requirement;
targeted API inspection and the complete checks below found no such requirement.
The catalog now requests `^24.19.0`, and a normal `pnpm install --lockfile-only` resolves
24.19.0. This aligns declarations with the supported runtime without changing application APIs.

The [exact registry package](https://registry.npmjs.org/@types/node/24.19.0) and its archive
were reviewed: MIT license, declaration files without runtime JavaScript or install scripts,
TypeScript minimum 5.6 (workspace: 5.9.3), and only `undici-types` as a dependency. The latter
remains locked at 7.24.6. Registry publication was `2026-09-25T22:09:25.850Z`; the package had
passed the unchanged 1,440-minute minimum release age when installed. No age exemption was added.

### 2026-09-27 Quality CI security remediation

The CI repair advances the existing build-tool overrides to `fast-uri` 3.1.6 and `js-yaml` 4.3.2.
The official registry metadata lists BSD-3-Clause and MIT respectively, no install lifecycle scripts,
no dependencies for fast-uri and the unchanged `argparse ^2.0.1` dependency for js-yaml. Publication
dates are 2026-08-23 and 2026-08-26, both beyond the unchanged 1,440-minute release-age protection.
The patched floors are confirmed by the [fast-uri advisory](https://github.com/advisories/GHSA-5jgf-p345-68v8)
and [js-yaml advisory](https://github.com/advisories/GHSA-2883-xcg3-v3hh). pnpm regenerated the lockfile
and installed with `--frozen-lockfile`; no new dependency, ignored advisory or age exemption was added.

`pnpm audit --audit-level high` now passes: zero high/critical, four moderate findings remain for
the existing qs and Vitest/mocker versions listed above. This is not a claim of a clean full audit.
