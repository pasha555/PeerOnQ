# Vulnerability disclosure

Please report suspected PeerOnQ vulnerabilities through GitHub's private vulnerability reporting for
this repository. Include the affected version/commit, impact, prerequisites, minimal reproduction,
and any sanitized logs. Do not include passwords, tokens, private keys, real screen/clipboard/file
content, or personal documents.

Do not publicly disclose an unpatched issue, access data beyond what is necessary to demonstrate it,
degrade shared services, persist on systems, or test devices/accounts without authorization. PeerOnQ
maintainers should acknowledge a report, establish a private coordination channel, triage severity,
and provide status updates. A fixed public deadline cannot be promised before a staffed security
contact/SLA is approved; that staffing is a broad-public-release gate.

For active exploitation or suspected signing-key compromise, follow
[`docs/INCIDENT_RESPONSE.md`](docs/INCIDENT_RESPONSE.md) immediately.
